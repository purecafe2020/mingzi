Questions, answered honestly

Is this a real Chinese name, or a gimmick?

A real name, built the way Chinese speakers build one: surname first, meaningful given characters after. It is not an official document — for passports or visas you still use your legal name — but for daily life, teachers, colleagues and seals, this is a name you can actually use.

Can I pick a different name if I don't like it?

Yes — try variants of your name (full name, nickname, middle name); each gets its own result. The paid certificate includes a round of adjustments with a native reader.

Is it safe to get it tattooed?

Every result passes an automated cultural-safety scan (no unlucky homophones, no dated characters). For a permanent tattoo, the certificate's tattoo sheet shows stroke-by-stroke layout you can hand to your artist — worth the few dollars before something permanent.

Why is the name free?

Because the name should be given, not sold. Mingzi charges only for the handmade keepsakes around it — calligraphy, seals, certificates — the way a calligrapher would.

How do I pronounce it?

Each character shows pinyin with tone numbers. The paid certificate adds audio recorded at natural speed, plus tone-flow tips so it sounds like a name, not a vocabulary drill.
